# PPT 메이커 (POC)

P-GPT 답변을 붙여넣으면 회의용 PPT 미리보기를 만들고, 미리보기에서 고친 뒤 편집 가능한 `.pptx`로 내려받는 웹앱입니다.

## 사용법
1. ⚙ 설정 → Gemini API 키 입력 ([Google AI Studio](https://aistudio.google.com/apikey)에서 무료 발급). 키는 이 브라우저에만 저장됩니다.
2. 답변을 Ctrl+V로 붙여넣습니다. 웹 화면의 표를 복사하면 표 구조가 유지되고, 마크다운도 됩니다.
3. 장수(1장 / 3장 / 5장 / 추천)와 양식(Apple / Toss / POSCO)을 고르고 **PPT 생성**을 누릅니다.
4. 미리보기에서 편집합니다.
   - 클릭: 선택·이동 · 모서리 ◢: 크기 조절 · 더블클릭: 글자 수정
   - 목록에서 Tab: 들여쓰기 · Delete: 요소 삭제 · Ctrl+Z: 되돌리기
5. **완료 · PPT 다운로드**

> ⚠ 무료 Gemini 키에 넣은 내용은 구글이 서비스 개선에 쓸 수 있습니다. **사내 실문서는 넣지 마세요.**

## 설계 요약
| 항목 | 결정 |
|---|---|
| 구조 | 서버 없음. 정적 페이지(GitHub Pages)에서 브라우저가 LLM을 직접 호출 |
| LLM 역할 | 내용만 슬라이드 설계도(JSON)로 정리. 디자인은 앱 템플릿이 담당 |
| 장수 | 1장 = 한 장 요약(압축 허용) / 3·5장 = 거의 무손실 / 추천 = 무손실 기준으로 LLM이 장수 결정. 압축되면 안내 띠 표시 |
| 양식 | 세 양식이 같은 좌표를 쓰고 색·모양만 다름 → 편집한 뒤 양식을 바꿔도 배치 유지. 16:9, 맑은 고딕 |
| 부품 | 제목 띠 · 소제목 · 글머리(2단계) · 표 · 흐름도(화살표) · ※박스 · 결론박스 |
| 출력 | PptxGenJS로 진짜 PPT 개체(글상자·표·도형)를 만들어 PowerPoint에서 계속 수정 가능 |

## 파일
- `js/llm.js`: LLM 호출과 프롬프트. **사내 LLM으로 바꿀 때는 `callLLM` 함수만 고치면 됩니다** (입력: 프롬프트 문자열, 출력: JSON 객체)
- `js/layout.js`: 설계도 → 좌표 배치 (넘치면 글자를 줄이고, 적으면 키움)
- `js/themes.js`: 양식 3종 · `js/render.js`: 미리보기 · `js/export.js`: .pptx 생성
- `js/app.js`: 화면, 편집, 붙여넣기 변환 · `js/samples.js`: 예시 입력
- `test.js`: 배치 점검 (`node test.js`)
